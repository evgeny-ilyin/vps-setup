# Как правильно увеличить SWAP в Ubuntu 24.04

Практическая инструкция по увеличению файла подкачки, настройке `swappiness` и проверке конфигурации.

> **Важно:** команды ниже выполняются от `root` или через `sudo`. Перед изменением SWAP проверьте текущую конфигурацию: не удаляйте файл и не отключайте раздел, пока не убедитесь, что это именно старое пространство подкачки.

## 1. Проверяем текущий SWAP

Посмотрите, какие пространства подкачки активны:

```bash
swapon --show
```

В колонке `NAME` будут указаны пути к файлам или разделам, например:

- `/swapfile` — файл подкачки;
- `/swap.img` — другой файл подкачки;
- `/dev/vda2` — раздел диска, используемый как SWAP.

Дополнительно проверьте состояние памяти:

```bash
free -h
```

## 2. Увеличиваем SWAP до 4 ГБ

Эти шаги подходят, если вы используете **файл подкачки `/swapfile`**. Если он уже существует, сначала убедитесь, что это нужный файл и что его можно пересоздать.

### Шаг 1. Отключаем текущий SWAP

```bash
swapoff -a
```

> На сервере с небольшим объёмом RAM отключение SWAP может увеличить нагрузку на память. Убедитесь, что оперативной памяти достаточно для текущих процессов.

### Шаг 2. Создаём файл подкачки на 4 ГБ

```bash
fallocate -l 4G /swapfile
```

Если `fallocate` завершился ошибкой, можно создать файл командой:

```bash
dd if=/dev/zero of=/swapfile bs=1M count=4096 status=progress
```

**Примечание:** если `/swapfile` уже существует, не запускайте создание файла вслепую. Убедитесь, что старый файл можно заменить. При необходимости сначала удалите его после отключения и проверки конфигурации.

### Шаг 3. Устанавливаем безопасные права

```bash
chmod 600 /swapfile
```

### Шаг 4. Форматируем файл как SWAP

```bash
mkswap /swapfile
```

### Шаг 5. Включаем новый SWAP

```bash
swapon /swapfile
```

### Шаг 6. Настраиваем автоматическое подключение при загрузке

Откройте файл `/etc/fstab`:

```bash
vi /etc/fstab
```

Убедитесь, что в нём есть строка:

```fstab
/swapfile none swap sw 0 0
```

Если строка уже есть, не добавляйте её повторно. Если в файле настроен другой SWAP, сначала проверьте его, чтобы не оставить ненужную запись.

## 3. Настраиваем `swappiness`

`vm.swappiness` влияет на то, насколько активно ядро Linux использует SWAP. Значение по умолчанию часто равно `60`. Для некоторых небольших серверов можно попробовать `10` или `20`, но оптимальное значение зависит от нагрузки и доступной RAM.

### Шаг 1. Проверяем текущее значение

```bash
cat /proc/sys/vm/swappiness
```

### Шаг 2. Меняем значение до следующей перезагрузки

Например, устанавливаем `20`:

```bash
sysctl vm.swappiness=20
```

### Шаг 3. Сохраняем настройку

Откройте конфигурацию:

```bash
vi /etc/sysctl.conf
```

Добавьте строку:

```ini
vm.swappiness=20
```

Если параметр уже указан, измените существующее значение вместо добавления дубликата.

Чтобы применить настройки из файла без перезагрузки, выполните:

```bash
sysctl -p
```

## 4. Удаляем старый SWAP

После создания нового SWAP проверьте активные пространства ещё раз:

```bash
swapon --show
```

Если одновременно активны новый и старый SWAP, сначала определите, что именно используется: файл или раздел.

### Вариант A. Старый SWAP — файл, например `/swap.img`

1. Отключите именно старый файл:

   ```bash
   swapoff /swap.img
   ```

2. Откройте `/etc/fstab`:

   ```bash
   vi /etc/fstab
   ```

3. Найдите запись старого файла, например:

   ```fstab
   /swap.img none swap sw 0 0
   ```

4. Удалите эту строку или закомментируйте её, добавив `#` в начало.
5. Сохраните файл.
6. Убедившись, что путь указан верно и файл больше не нужен, удалите его:

   ```bash
   rm /swap.img
   ```

**Внимание:** замените `/swap.img` на фактический путь старого файла из `swapon --show`. Не удаляйте `/swapfile`, если это новый SWAP.

### Вариант B. Старый SWAP — раздел, например `/dev/vda2`

Не удаляйте раздел и не форматируйте его. Чтобы перестать использовать его как SWAP:

1. Откройте `/etc/fstab` и найдите запись, относящуюся к этому разделу (она может ссылаться на устройство или UUID).
2. Убедитесь, что запись относится именно к старому SWAP.
3. Удалите или закомментируйте эту запись.
4. Отключите раздел:

   ```bash
   swapoff /dev/vda2
   ```

   Замените `/dev/vda2` фактическим именем устройства.

> Если раздел управляется средствами хостинга или используется в другой конфигурации, сначала уточните назначение у провайдера. Для отключения SWAP обычно не требуется удалять сам раздел.

## 5. Проверяем конфигурацию

### Проверяем `/etc/fstab`

```bash
mount -a
```

Если команда завершилась без сообщений об ошибках, это хороший признак, но она **не гарантирует**, что все записи SWAP корректны. Для дополнительной проверки выполните:

```bash
swapon --show
```

### Проверяем размер SWAP и память

```bash
free -h
```

В выводе найдите строку `Swap`. Если настроен только новый файл на 4 ГБ, общий размер SWAP должен быть примерно 4 ГБ.

### Проверяем `swappiness`

```bash
cat /proc/sys/vm/swappiness
```

Если вы выбрали значение `20`, команда должна вывести:

```text
20
```

## Краткий список команд для проверки

```bash
swapon --show
free -h
cat /proc/sys/vm/swappiness
mount -a
```

После настройки убедитесь, что активен нужный SWAP, в `/etc/fstab` нет лишних записей, а `swappiness` имеет ожидаемое значение.
